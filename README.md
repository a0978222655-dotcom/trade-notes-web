# 拾序｜手機交易工作台

網站：https://a0978222655-dotcom.github.io/trade-notes-web/

手機優先的 Prop Firm 交易日誌，支援帳號規則、生命線、盈虧日曆、成本、復盤、照片與完整 JSON 備份。

此次更新：帳號詳情頁加入刪除功能與資料數量確認，可清除試用帳號及所屬交易、復盤、收支與照片；其他帳號和共用照片會保留。刪除最後帳號後仍維持空白個人工作台。

通過27項自動測試、8項帳號刪除手機檢查、14項照片與捲動檢查、11項生命線檢查、型別檢查與正式建置。

紀錄與照片留在使用者目前的瀏覽器。此儲存庫僅發布靜態網站，不包含個人交易資料或照片。
